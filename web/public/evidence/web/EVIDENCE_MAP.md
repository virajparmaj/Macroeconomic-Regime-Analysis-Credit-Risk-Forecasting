## Existing website export audit / claim corrections

`analysis/export.py` is not an authoritative computation pipeline. `analysis/export_web.py` mixes computations, rounded exports, hard-coded metrics and old scratch-directory prediction paths. Its `horizon.json` preserves unknown-future-label problems; `modelMetrics.json` includes old inference; `warnings.json`, `granger.json`, `keyNumbers.json` contain values not suitable as the new primary evidence layer. The new page uses an independently checked export of existing source artifacts, without fitting models. Legacy export files are not imported by the new experience.

The old `timeline.json` levels and stress scores match stored source values at their display rounding; `preds.json` matches prediction CSVs rounded to three decimals but labels origins simply `d`. The old `aggregation.json` contains observed-day summaries even where old copy called them the modeled legacy mean. `regimeSplit.json` point estimates are descriptive and its row-bootstrap bands are not dependent-time inference; `xcorr.json` is descriptive lagged correlation, not a causal explanation. These exports were audited, then superseded in the active page by `research.json`.

Remove the universal three-month predictability limit, crisis-warning product claim, range-as-speed claim, universal macro-failure claim, causal explanations from correlation, and fully point-in-time language. Preserve original work as historical context. Use pp for levels/MAE/RMSE and pp² for MSE (1 pp = 100 bp).

## Display contract

Each result group identifies source, status, target definition, units, dates, horizon, sample count and benchmark where relevant. Prediction charts use persisted origin-level records and distinguish origins from realized target dates. Descriptive series have no forecast horizon or benchmark. No synthetic model paths or confidence bands are added.

Additional coverage limit: the daily source ends on August 1, 2022, so the final August monthly observation is a partial-month aggregate. The macro stress export has 250 months after its 60-month sentiment warmup. The regime-enriched CSV has 309×21 cells by columns including date; it is not the 306×23 Phase 1 feature artifact.

## Implemented artifact path

`web/scripts/export_research.py` reads original inputs and stored evidence, verifies source hashes/alignment/metrics, and writes `web/src/data/research.json` plus verbatim downloadable source snapshots in `web/public/evidence/`. The manifest hashes those sources and the generated output. Full daily-source counts and monthly summaries are verified; only the March 2020 daily values displayed in the detail chart are shipped in the JavaScript data payload. No prediction paths are created for log-only change models. Original notebooks and evidence are read-only throughout.

The interface provides 83 searchable feature records, 23 model/experiment records, separate regime definitions, keyboard-accessible chart inspectors, aggregation and horizon controls, and summary/technical reading modes. Model summaries preserve their own evaluation context; no historical-versus-corrected universal leaderboard is created.
