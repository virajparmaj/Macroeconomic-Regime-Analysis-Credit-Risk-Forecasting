# Executed credit-spread research study

Read the [empirical draft](paper_preparation/13_EXECUTED_MANUSCRIPT.md) for measured findings and the [paper package](paper_preparation/00_README.md) for scope, literature, validity, results and limitations.

The implementation is in [study/](study/README.md). It reconstructs complete-month targets, enforces label maturity and train-only preprocessing, compares matched spread/macro/regime models, separates stress occupancy from entry warnings, and produces paired calendar-block uncertainty. All 72 core jobs, 236 sensitivity jobs and 16 later-period jobs completed. A second 72-job core run exactly reproduces predictions. The suite passes 58 tests; six notebook readers execute.

The primary incremental ridge MSE gain is 39.36% (95% interval −7.92% to 55.79%). Endpoint persistence is still better. This supports a cautious empirical research note, not an established forecasting breakthrough.
